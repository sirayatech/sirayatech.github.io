1.2 USDT

📄️ 1.2.1 Add new record

Instruct to create USDT payment records for users

📄️ 1.2.2 Edit record

We can edit records that are in the [Open] state - these are records where the user has not yet confirmed payment.

📄️ 1.2.3 View detail

You can view details of all records. The detailed information displayed when viewing records in different states will be different.

📄️ 1.2.4 Delete record

Except for records with a status of "Processing", other records can be deleted.
