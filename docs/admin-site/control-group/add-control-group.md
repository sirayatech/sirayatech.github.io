# 1.3.1 Add new control group
Control group to group and manage domains, each domain belongs to only 1 control group

In control group function, we have two types of contract group 
- Control Group from customer account (Main account) - A Control Group that is automatically synced and The name of this Control Group cannot be modified.
- Control Group from Siraya account (Main account) - this Control Group’s name can be customized by root Account.
    + Control group can be created 
    + Control group can be synced from CDNW

With the control group synced from CDNW, we need to assign company, contract and package for it after being synced. The system will automatically synchronize every 5 hours
